
# Sistema Web de Pollería

## Descripción

Sistema web para gestionar los pedidos en sala y las comandas de una pollería.

## Objetivo

Facilitar la gestión de mesas, productos, pedidos, cocina y pagos.

## Tecnologías

- React
- TypeScript
- Vite
- Firebase
- Cloud Firestore

## Módulos

1. Inicio de sesión.
2. Gestión de mesas.
3. Gestión de productos.
4. Gestión de pedidos.
5. Cocina.
6. Seguimiento.
7. Consumo.
8. Caja.
9. Reportes.

## Roles

- Administrador.
- Mozo.
- Cocina.
- Cajero.

## Instalación

Ejecutar:

`npm install`

Iniciar el sistema:

`npm run dev`

## Base de datos

Se utiliza Cloud Firestore para almacenar usuarios, mesas, productos, pedidos y pagos.
